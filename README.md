# H4cknomous

Personal security research and technical portfolio.

This site is built with Next.js and deployed on Vercel. It brings together security research, technical write-ups, tooling, and selected projects.

## Stack

- Next.js App Router
- TypeScript
- CSS
- Vercel

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Content

Research pages and write-ups live in the Next.js app. The Intigriti Challenge 1126 write-up is intentionally not published here until the challenge organizers confirm the publication window is open.

## Deployment

Connect this repository to Vercel. Every push to `main` will trigger a production deployment, and pull requests can receive preview deployments.
